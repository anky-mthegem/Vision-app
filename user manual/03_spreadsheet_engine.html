Directed Acyclic Graph (DAG) Execution

Multi-Cell DAG Execution Pipeline

Topological Sorting Algorithm

When an inspection job compiles, VisionStudio constructs an adjacency list representing all cell interdependencies. A depth-first topological search orders the cells so that every parent cell computes before its children:

Cell Label Formula Depends On Role
A0 Camera Image =AcquireImage() None Root camera buffer capture
B2 IC Alignment =PatMax(A0) A0 Locates part centroid and rotation angle
C3 Hole Inspection =FindBlobs(A0, threshold=120) A0 Detects presence/absence of drilled holes
D4 Pin Diameter =FindCircle(A0) A0 Measures radial caliper circle
E5 Quality Gate =If(B2.Score >= 60.0, "PASS", "FAIL") B2 Evaluates pass/fail status and trips PLC bit

Cell Attribute Referencing Syntax

Tools output structured result objects. Downstream cells reference specific attributes using dot notation:

  • B2.Score — Matching confidence percentage (0.0 to 100.0%).
  • B2.X & B2.Y — Subpixel centroid coordinates.
  • B2.Angle — Rotational orientation in degrees (-180° to +180°).
  • C3.Count — Total count of detected foreground blobs.
  • D4.Radius — Fitted circle radius in pixels.
