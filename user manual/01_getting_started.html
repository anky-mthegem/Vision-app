CHAPTER 01 • GETTING STARTED

Getting Started & System Architecture

A comprehensive guide to installation, runtime environments, user interface anatomy, and the Clean Standby operational model of VisionStudio.

01

System Requirements & Installation

VisionStudio runs seamlessly across Windows 10/11 and industrial Linux edge platforms (Ubuntu 20.04+, Debian, Raspberry Pi OS).

Hardware Recommendations

  • Processor: Intel Core i5/i7 (8th Gen+), AMD Ryzen 5+, or ARM64 (Raspberry Pi 4/5 for edge inference).
  • Memory: 8 GB RAM minimum (16 GB recommended for high-resolution cameras).
  • Graphics / Video: DirectShow compatible USB3 / GigE Vision interface or network adapter.
  • Network: 1 Gbps Ethernet connection for industrial PLC and RTSP IP camera bandwidth.

Software Installation

Terminal 
# 1. Clone or download the VisionStudio repository
cd Vision-app

# 2. Install required dependencies
pip install -r requirements.txt

# 3. Launch VisionStudio
python main.py
02

User Interface Anatomy

VisionStudio UI Layout
1️⃣

Top Toolbar

Camera protocol selection, connection string, live camera reconnection, manual trigger, WebHMI shortcut, and PLC dialog.

2️⃣

Live Viewport

High-FPS camera stream overlaying subpixel crosshairs, green/red bounding boxes, caliper rakes, and neural detection reticles.

3️⃣

Spreadsheet Table

Formula bar with cell coordinate selector, live results, execution latency in milliseconds, and individual cell enable checkboxes.

4️⃣

Tool Catalog

Categorized tabs with one-click additions for AI, pattern matching, edge calipers, defect blobs, barcodes, OCR, and PLC writes.
