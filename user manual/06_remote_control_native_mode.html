CHAPTER 06 • REMOTE TCP PROTOCOL

Native Mode Remote Automation (Port 1023)

Control VisionStudio over raw TCP sockets using standard ASCII commands. Query cells, trigger inspections, and read cycle times from any PLC, robot, or script.

01

Command Set Reference

Command Syntax Expected Response Description
GV GV <cell> 1\r\n<value>\r\n Queries cell value (e.g. GV E5 returns 1\r\nPASS\r\n).
GV Attribute GV <cell.prop> 1\r\n<float>\r\n Queries cell property (e.g. GV B2.Score or GV B2.X).
SW SW 1\r\n Software Trigger: Fires camera acquisition immediately.
SE 8 SE 8 1\r\n Synchronous Event Trigger #8.
SO SO <0|1> 1\r\n Sets sensor online state (1=Online, 0=Offline).
RB RB 1\r\n<buffer>\r\n Reads full inspection result string buffer.
RT RT 1\r\n<ms>\r\n Returns total cycle time of last inspection in milliseconds.

Testing with Python Socket

Python 3 
import socket

s = socket.socket()
s.connect(("127.0.0.1", 1023))
print("Connected:", s.recv(1024).decode())

# Send software trigger
s.sendall(b"SW\r\n")
print("Trigger ACK:", s.recv(1024).decode())

# Read decision
s.sendall(b"GV E5\r\n")
print("Decision:", s.recv(1024).decode())
s.close()
