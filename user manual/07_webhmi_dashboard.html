CHAPTER 07 • WEBHMI MONITORING

WebHMI Remote Shop-Floor Dashboard

Access real-time machine vision inspection telemetry, live annotated video, and production quality metrics from any web browser or shop-floor tablet.

01

Accessing the WebHMI Dashboard

VisionStudio runs an integrated FastAPI and Uvicorn server on port 8080.

🖥️

Local Access

Open http://localhost:8080 on the host machine or click "Open WebHMI" in the VisionStudio toolbar.

📱

Shop-Floor Tablets & Phones

Navigate to http://<HOST_IP>:8080 (e.g. http://192.168.1.50:8080) from any browser on the local plant network.

REST API Endpoints

Method Endpoint Return Type Function
GET /video_feed multipart/x-mixed-replace Live MJPEG stream with dynamic graphics overlays and bounding boxes.
POST /api/trigger JSON Remotely fires camera acquisition and job evaluation.
GET /api/stats JSON Returns overall pass/fail status, cycle times, yield %, and part counts.
WS /ws/telemetry WebSocket High-frequency streaming telemetry for custom dashboards and SCADA systems.
