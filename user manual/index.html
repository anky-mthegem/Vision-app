VisionStudio User Manual

VisionStudio is a modern, high-performance industrial computer vision and automated inspection platform. It seamlessly unites multi-protocol camera acquisition, subpixel geometric measurement, real-time AI deep learning (YOLOv8), a spreadsheet Directed Acyclic Graph (DAG) formula execution model, and enterprise fieldbus communications with Siemens, Delta, Beckhoff, and Raspberry Pi hardware.

Getting Started & Architecture

QUICK START

VisionStudio delivers a unified desktop environment for visual quality control, automated assembly inspection, part localization, and factory floor PLC handshakes.

System Architecture Highlights

⚡

Asynchronous Inspection Core

Camera streaming and vision algorithms run on separate background worker threads. The live display never freezes, drops frames, or stutters during intensive AI inference.

🌱

Clean Standby Startup

On initial launch, VisionStudio operates strictly in camera standby mode (A0 = AcquireImage()). No heavy tools execute until explicitly selected or configured by the operator.

📊

DAG Spreadsheet Model

Inspection sequences are evaluated via Directed Acyclic Graph dependency trees. Downstream cells automatically compute in topological order when upstream inputs update.

🛡️

Deterministic Cycle Times

High-resolution timing benchmarks per-cell latency (last_exec_ms), aggregate cycle time, production counters, and automated yield tracking.

Launching VisionStudio

1

Desktop GUI Launch (Recommended)

Double-click Launch_VisionStudio.bat or run the command below. The desktop GUI, Native Mode TCP server (port 1023), and WebHMI dashboard (port 8080) will initialize automatically.

Powershell / CMD 
python main.py
2

Headless Industrial Server Mode

For headless industrial rack-mount PCs, fanless edge controllers, or Docker containers without graphical displays, use the --headless flag:

Powershell / CMD 
python main.py --headless --port 8080 --native-port 1023
💡
Performance Tip: When running high-speed production lines exceeding 30 parts per second, headless mode conserves GPU and rendering cycles, directing maximum compute throughput to ONNX inference and PLC communication.

Camera Subsystem & Protocols

HARDWARE INTEGRATION

VisionStudio incorporates a multi-protocol camera driver capable of interfacing with standard industrial USB3 cameras, Ethernet RTSP video streams, network HTTP snapshot cameras, and a built-in Synthetic Part Simulator.

Protocol Source Identifier Format Typical Hardware Recommended Settings
USB / DirectShow 0, 1, 2 Industrial USB3 Vision cameras, DirectShow webcams, microscope cameras Resolution: 1280x720 / 1920x1080 @ 30-60 FPS
RTSP Stream rtsp://user:pass@192.168.1.100:554/stream GigE IP security cameras, factory surveillance, PoE inspection sensors H.264 / H.265 baseline profile with TCP transport
HTTP Snapshot http://192.168.1.100/snapshot.jpg Web-enabled smart cameras, remote inspection stills, optical sensors Keep-Alive enabled, JPEG quality ≥ 85
Synthetic Simulator Synthetic Part Simulator Built-in hardware-free test generator with moving PCBs, fiducials, IC chips & flaws Default test environment for offline recipe authoring

Triggering Modes

  • Continuous Free-Run: The camera streams frames continuously at the sensor's native frame rate. The spreadsheet runs automatically on newly arrived frames.
  • Software Trigger [SW]: Clicking the TRIGGER [SW] button in the top toolbar or issuing the SW command over Native Mode TCP captures an image on-demand.
  • Hardware Trigger (Opto-Isolated GPIO): Connecting an inductive proximity sensor or photoelectric beam sensor to Raspberry Pi GPIO Pin 4 immediately triggers inspection upon part arrival.

Automatic UDP Network Discovery (Port 1069)

VisionStudio runs a background network beacon daemon on UDP port 1069. Industrial network discovery tools broadcast probe packets on the local subnet to instantly locate VisionStudio sensors, query IP configuration, MAC address, and device online states without manual IP configuration.

Spreadsheet DAG Execution Engine

CORE LOGIC

VisionStudio organizes inspection logic using a visual Directed Acyclic Graph (DAG) spreadsheet grid. Every cell represents an image acquisition, vision algorithm, coordinate transform, or decision rule.

📊 Active Multi-Tool Inspection DAG Pipeline
🔍 Click to zoom full-size

How Dependency Resolution Works

When you enter a formula such as =If(B2.Score >= 60.0, "PASS", "FAIL"), the engine inspects references to other cells (e.g. B2), establishes a directed edge in the dependency graph, and topologically sorts all cells. Execution always flows forward:

Topological Execution Order 
[A0: AcquireImage] ──► [B2: PatMax] ──► [D4: Distance] ──► [E5: Quality Gate (If)]
                           │
                           └──────────────► [C3: FindBlobs] ───────┘

Cell Enable / Disable Checkboxes

Every row in the spreadsheet table features an interactive Run checkbox in column 0. Unchecking a cell instantly disables its execution, skipping downstream dependencies and conserving processing time during line commissioning or partial recipe testing.

📌
Root Cell A0: Cell A0 is reserved exclusively for the primary camera image acquisition (=AcquireImage()). It cannot be deleted or disabled, guaranteeing that downstream tools always possess a valid image buffer.

Industrial Vision Tools Catalog

REFERENCE MANUAL

VisionStudio provides a rich catalog of 25+ industrial vision functions categorized into pattern alignment, blob inspection, edge calipers, identification, filtering, and geometry.

1. Pattern Matching & Alignment

=PatMax(A0)
Geometric contour and gradient-vector pattern matching with full 360° rotation and scale tolerance. Returns Score, X, Y, Angle.
=TrainPatMax(A0, roi=[100, 100, 200, 200])
Trains a new geometric golden pattern template from the designated Region of Interest (ROI).

2. Presence, Absence & Defect Inspection

=FindBlobs(A0, threshold=128, min_area=50)
Morphological connected-component extraction. Computes blob areas, circularity, bounding boxes, and centroids.
=DetectFlaw(A0, sensitivity=35)
Surface anomaly and scratch detection comparing current frame against a golden baseline template.
=Histogram(A0)
Measures grayscale light intensity, mean luminance, standard deviation, peak bin, and contrast range.

3. Edges & Caliper Measurement

=FindLine(A0)
Projects perpendicular caliper search rakes, locates subpixel gradient edge transitions, and fits boundary lines.
=FindCircle(A0)
Radial caliper rays projecting outward to locate circular edges, fitting center coordinate (X, Y) and radius.
=Caliper(A0)
High-precision distance measurement between edge pairs (e.g. pin gap, component width, groove clearance).
=EdgeCount(A0)
Scans along an inspection segment and counts light-to-dark and dark-to-light boundary crossings (e.g. connector pins, gear teeth).

4. Identification & OCR

=ReadIDMax(A0)
Industrial 1D barcode (Code 128, Code 39, EAN-13) and 2D matrix (QR Code, DataMatrix) decoding. Returns Text, Type, Polygon.
=ReadOcrMax(A0, regex="[A-Z0-9]+")
Optical character recognition for embossed or laser-marked alphanumeric lot numbers, expiration dates, and serial codes.

5. Image Filters & Color Segmentation

=ExtractColor(A0, color="GREEN")
HSV color space isolation (RED, GREEN, BLUE, YELLOW, WHITE). Returns pixel count and percentage coverage.
=ImageFilter(A0, filter="Gaussian", ksize=5)
Morphological and convolutional image filters: Gaussian, Median, Sobel, Laplacian, MorphOpen, MorphClose.
=Binarize(A0, method="Otsu")
Automatic image segmentation converting grayscale to high-contrast binary masks (Otsu, Adaptive, Fixed).

6. Geometry, Logic & Decision Rules

=Distance(B2.X, B2.Y, C3.X, C3.Y)
Euclidean distance between two coordinates in pixels or calibrated millimeters.
=Angle(B2.X, B2.Y, 500, 300)
Calculates slope orientation angle (-180° to +180°) between two coordinates.
=If(B2.Score >= 75.0 and D4 < 50.0, "PASS", "FAIL")
Conditional quality gate. When evaluated, flags cell as PASS or FAIL, driving the overall inspection verdict and PLC outputs.

Industrial PLC & Hardware Communications

FACTORY AUTOMATION

VisionStudio bridges machine vision directly to factory programmable logic controllers (PLCs), industrial robots, and digital input/output lines without requiring intermediate OPC servers or middleware.

📡
Interactive Toolbar Dialog: Click the 📡 PLC & Devices button in the main window toolbar to open the centralized configuration dialog. Every tab includes one-click "Test Connection (Ping)" and "Send Test Inspection Result" verification buttons!

1. Siemens S7 PLC Integration

📡 Siemens S7 PLC Communications Configuration Dialog
🔍 Click to zoom full-size

VisionStudio transmits a high-speed 16-byte batch payload directly into a Siemens DataBlock (DB) on every cycle:

Byte Offset Data Type PLC Variable Description
Byte 0.0 BOOL bPass True (1) when overall inspection decision is PASS.
Byte 0.1 BOOL bFail True (1) when overall inspection decision is FAIL.
Byte 0.2 BOOL bVisionReady Heartbeat / ready handshake indicating camera is armed.
Bytes 2 - 3 INT16 nPartCount Cumulative inspection cycle counter.
Bytes 4 - 7 REAL32 (Float) fPartX Part alignment centroid X coordinate.
Bytes 8 - 11 REAL32 (Float) fPartY Part alignment centroid Y coordinate.
Bytes 12 - 15 REAL32 (Float) fPartAngle Part rotational orientation in degrees.
=WriteSiemens(E5, ip="192.168.1.10", db=1, byte=0)
Dispatches cell E5 result and part coordinate offsets to Siemens PLC at 192.168.1.10, DB 1.

2. Delta PLC via Modbus TCP (Port 502)

📡 Delta PLC Modbus TCP Configuration Dialog
🔍 Click to zoom full-size

Supports Delta DVP-SE, AS200, AS300, and AH500 series controllers with native Delta register mapping:

  • D-Registers: D0 maps automatically to Modbus holding register 0x1000 (4096).
  • M-Coils: M0 maps automatically to Modbus discrete coil 0x0800 (2048).
  • Formula Syntax: =WriteModbus(E5, ip="192.168.1.50", reg=100)

3. Beckhoff TwinCAT ADS & Ethernet Robot Communication

⚡

Beckhoff TwinCAT ADS

Communicates natively over TCP port 48898 (ADS router) directly into TwinCAT %M memory area (IndexGroup 0x4020).

=WriteBeckhoff(E5, ip="192.168.1.20", offset=100)

Industrial Ethernet Devices

TCP/UDP client and server interfacing with ABB, KUKA, Fanuc, and Universal Robots using JSON, CSV, or ASCII telegrams.

Native Mode Remote Automation (TCP Port 1023)

REMOTE PROTOCOL

VisionStudio runs a high-speed Native Mode Telnet server on TCP port 1023 (standard port 23 compatible). External PLCs, HMIs, and software systems can control the vision engine using standard ASCII text commands.

Command Example Usage Response Format Description
GV <cell> GV E5 1\r\nPASS\r\n Get Value: Queries the current evaluated value of specified cell coordinate.
GV <cell.prop> GV B2.Score 1\r\n94.8\r\n Get Attribute: Queries discrete property (e.g. Score, X, Y, Angle).
SW SW 1\r\n Software Trigger: Fires instantaneous image acquisition and DAG re-evaluation.
SE 8 SE 8 1\r\n Event Trigger: Triggers synchronous inspection event #8.
SO <0|1> SO 1 1\r\n Set Online: Puts system Online (1) or Offline (0).
RB RB 1\r\nPASS,B2=94.8,D4=12.4\r\n Read Result Buffer: Returns formatted string of all active inspection decision values.
RT RT 1\r\n28.4\r\n Read Time: Returns last inspection execution cycle time in milliseconds.

Python Native Mode Client Example

Python 3 
import socket

# Connect to VisionStudio Native Mode TCP Server
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.connect(("127.0.0.1", 1023))

# Read welcome banner
print(sock.recv(1024).decode())

# Send software trigger
sock.sendall(b"SW\r\n")
print(sock.recv(1024).decode())

# Query decision cell E5
sock.sendall(b"GV E5\r\n")
result = sock.recv(1024).decode()
print("Inspection Verdict:", result)

sock.close()

WebHMI Remote Shop-Floor Dashboard

REMOTE MONITORING

Every instance of VisionStudio hosts an integrated FastAPI WebHMI server at http://localhost:8080. Operators and plant supervisors can monitor live video, review inspection yield statistics, and trigger inspections from any web browser, iPad, Android tablet, or plant SCADA terminal.

Troubleshooting & Optimization Guide

DIAGNOSTICS

Common Diagnostic Scenarios

!

Camera Fails to Connect or Black Viewport

Verify the camera index in the top toolbar. If using USB, check indices 0, 1, or 2. For RTSP streams, verify that the IP camera allows sub-stream access without digest authentication restrictions.

!

Siemens S7 Connection Timeout on Port 102

Ensure that the Siemens CPU has "Permit access with PUT/GET communication from remote partner" enabled in TIA Portal device protection settings. Confirm that DataBlock DB1 is not set to "Optimized Block Access" (uncheck Optimized Access to enable standard byte offsets).

!

Spreadsheet Cell Displays #ERR or Red Highlight

Verify that cell formulas reference valid upstream coordinates. If cell E5 references B2.Score, ensure that cell B2 is enabled and currently contains a PatMax tool.
